Прототип мобильной игры в жанре MOBA

Отклонения от базового задания:
* Настроены кастомные приоритеты ИИ. Миньоны сначала бьют вражеских миньонов, затем базы, затем героя
* Добавлена механика нейтральной базы (Capture Point), которую можно захватить, простояв в ней 3 секунды
* После захвата нейтральная база начинает спавнить миньонов для команды захватчика
* Настроены волны мобов и крупные миньоны, которые фокусируются на захвате вышек
* Реализована система Game Over со сбором статистики убийств/смертей
